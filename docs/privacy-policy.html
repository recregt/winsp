WinSP Privacy Policy

Effective 2026-08-26 · Applies to the WinSP desktop application (Package identity: recregt.WinSP)

WinSP does not collect, store, transmit, or share any personal data. It has no network access, no analytics, no telemetry, and no user accounts.

What WinSP does on your device

WinSP is a local application launcher. Everything it does happens entirely on your own computer:

  • It reads the names and shortcut locations of installed Start Menu applications and Windows Settings pages to build a searchable index, held only in memory while the app runs.
  • If you enable “Start with Windows” from the tray menu, it registers WinSP with the standard Store-managed startup mechanism (Windows.ApplicationModel.StartupTask), visible in Settings > Apps > Startup. Disabling the option unregisters it.
  • It watches your Start Menu folders for changes so the search index can refresh automatically.

What WinSP does not do

  • No network requests of any kind — WinSP has no networking code and contacts no server, ours or anyone else's.
  • No telemetry, analytics, crash reporting, or usage tracking.
  • No accounts, sign-in, or advertising identifiers.
  • No data is ever sent off your device, because none is collected in the first place.

Permissions

WinSP runs as a standard full-trust Win32 desktop application. This lets it use ordinary Windows APIs — a global keyboard shortcut, a system tray icon, and the startup mechanism described above — and does not grant it administrator rights or access beyond what any desktop app on Windows already has.

Children's privacy

WinSP does not knowingly collect information from anyone, including children, because it does not collect information from anyone at all.

Changes to this policy

If this policy ever changes, the update will be published at this same address with a revised effective date, and noted in the project's release history.

Contact
